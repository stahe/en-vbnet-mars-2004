# Introduction to VB.NET Through Examples

👉 Related course: [Introduction to VB.NET Through Examples](https://stahe.github.io/en-vbnet-mars-2004/)

## Content

This course covers the following main topics:

- VB.NET basics
- Object-oriented programming
- Graphical user interfaces
- Event handling
- Database access
- TCP/IP programming
- Web services

## Objective

To provide a step-by-step introduction to VB.NET through practical examples, covering everything from the fundamentals to application-specific topics (GUI, networking, data, web services).
